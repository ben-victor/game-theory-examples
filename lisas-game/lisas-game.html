Lisa's Game

Rules: This is a variant of the classic Nim game, invented by Lisa Prisner. The board is a row of cards, each showing a 1, 2, or 3. Looking at the row from the current end, let x be the value of the last remaining card. On your turn you may:
  • Move 1: remove the last x cards.
  • Move 2: remove every card back to (and including) the second-most-recent card whose value is also x.
Players alternate turns with the computer. Whoever removes the last card loses.
